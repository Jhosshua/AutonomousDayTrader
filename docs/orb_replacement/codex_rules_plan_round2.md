### New v2 risks

- **P1 — The parent remainder can outlive an exit.** The plan says to cancel bracket legs, then close the owned quantity ([plan:90](</Users/mo/AutonomousDayTrader/PLAN_2026_09_28_orb_rules_match_orbstraddle.md:90>)). A partially filled market parent may still fill after the close, leaving new shares outside the controller’s position count. ORBStraddle’s exit code orders live entries first when canceling its own orders ([core.py:3992](</Users/mo/ORBStraddle/core.py:3992>)). **Fix:** cancel and confirm the parent remainder and both legs, reconcile final fills, then close the remaining owned quantity. Test an exit while the parent is still partially filling.

- **P1 — The plan does not specify a source-service handoff.** The local ORBStraddle spec records autopilot armed/live ([orbstraddle_spec.md:20](</Users/mo/AutonomousDayTrader/docs/orb_replacement/orbstraddle_spec.md:20>); the plan compares against its live board during shadow, then enables ADT the next session ([plan:67](</Users/mo/AutonomousDayTrader/PLAN_2026_09_28_orb_rules_match_orbstraddle.md:67>)). If both services use the same account, that can double entries and risk. **Fix:** require verified account isolation or a source-service shutdown and flat/open-order check before ADT order mode. Account sharing was not verified under your no-call constraint.

- **P1 — Generic strategy exits can bypass the named news-exit route.** The current handler catches any reason containing `EXIT` or `CONTRADICTION`, then uses generic flattening for positions not owned by tri or OR15 ([main.py:1735](</Users/mo/AutonomousDayTrader/backend/app/main.py:1735>), [main.py:1738](</Users/mo/AutonomousDayTrader/backend/app/main.py:1738>)). The plan names news contradiction, but its implementation checklist should explicitly route every generic exit reason through ORB ownership. Cover the API cancel route too: it calls `engine.cancel_order` directly ([main.py:3439](</Users/mo/AutonomousDayTrader/backend/app/main.py:3439>)).

- **P2 — The shadow gate compares outputs without requiring common inputs.** A matching board and verdict from independently timed scans does not prove both used the same tape, news cutoff or config. **Fix:** record and compare canonical input/config fingerprints in shadow; keep order mode disabled when the fingerprints or data windows differ.
