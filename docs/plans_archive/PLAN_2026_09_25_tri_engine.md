## Implementation architecture

- Add two fixed strategy states (`tsla_asymmetric_dual`, `cde_asymmetric_dual`) and a shared tri-engine controller, using the current engine, account, reconciliation, persistence, decision log, research recording, APIs and frontend. Keep the old OR15 state available for historical restoration/recovery, retired from new entries and active cards.
- Each new arm owns its tranche state and native protective orders. One aggregate stock position per symbol remains the account model; each tranche has its own quantity, target, deadline, stop, OCO identity and close identity. Fixed children bypass generic quote/bar matching and bracket ratchets. Main fill reconciliation delegates these ids to the owning controller before generic handling; completed aggregate trades and tranche details are written to the existing ledger.
- Persist entry intent, consumed signal, quantity, budget and deterministic broker ids before POST. Ambiguous responses reconcile the same identity without replacement entry. Partial entries cancel remaining quantity, protect filled shares and account explicitly for unequal TSLA allocation as an execution exception. Never silently claim an exact 50/50 fill if the broker returns an odd partial quantity.
- Native OCO per tranche, with buy-side exits for shorts. Protection failure invokes reconcile/cancel/flatten. Before timed/manual/feed-loss/account exits, settle and confirm cancellation of every applicable native leg, book race fills, then close only remaining broker quantity. Preserve retry identities across restart. Never infer a fill from HTTP acceptance, local triggers or synthetic prices.
- Validate restoration of phase, symbol, side, quantity, deadlines, fixed levels, child ownership, native ids and signal timing. Migrate only the known legacy strategy set. New arms initialize empty; unresolved old positions remain with their old controller. Include CDE in subscriptions even when production has an explicit watchlist.
- All generic paths (news exits, adaptation, manual tightening, flattening, restart, research hooks) must respect fixed ownership. Show both new arms and TSLA tranche progress using existing cream/pastel cards and responsive layouts. Display actual size/risk, windows, stop/targets/deadlines and paper execution mode in plain language.
